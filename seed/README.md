# 등산 앱 시드 데이터

산림청 등산로 공공데이터(2016-12-31 기준 조사, 2020 배포판)에서 수도권 7개 산군을 정제한 시드 데이터.

## 파일 구성

| 파일 | 내용 | 행 수 |
|---|---|---|
| mountains.csv | 산군 마스터 (행정구역 분할 파일 병합) | 7 |
| segments.csv | 등산로 구간 + WGS84 폴리라인 + 그래프 노드 | 1,732 |
| nodes.csv | 구간 끝점 노드 (5m 클러스터링, degree 포함) | 1,328 |
| spots.csv | 지점 (시종점/분기점/화장실/음수대/조망점 등) | 3,716 |
| entrances.csv | 입구(시종점)만 추출한 부분집합 | 286 |
| safety_points.csv | 산악구조 위치표지판 (119 신고용) | 97 |
| schema.sql | Supabase/Postgres DDL + courses/visits 앱 테이블 | - |

## 산군 구성 (병합 내역)

- 아차산·용마산 = 112150201(아차산) + 112600501(용마산, 서울)
- 관악산 = 116200201 + 116200604 + 116200704 + 116200904
- 북한산 = 113050202(백운대) + 114100801
- 청계산 = 116500804(서초) + 412900401(과천) — 가평/양평 동명이산 제외
- 인왕산 = 114100401
- 북악산 = 111100101
- 수락산·불암산 = 113500101(불암산) + 113500201(수락산) — 전남 불암산 동명이산 제외

## 좌표계

- 원본: EPSG:5186 (ITRF2000 TM 중부) → 전부 WGS84(EPSG:4326)로 변환 완료
- polyline 컬럼: [[lon, lat], ...] JSON 배열. 지도 SDK에 바로 사용 가능

## 알아둘 것

1. "코스"는 없다. segments는 평균 수십~수백 m의 마이크로 구간 그래프.
   코스는 courses 테이블에 segment_ids 배열로 직접 큐레이션해야 함.
   start_node/end_node로 그래프 연결 가능 (degree 3+ 노드 = 갈림길).
2. park_flag = 1: 가로등·운동기구 120m 근접 휴리스틱으로 분류한
   공원 산책로형 구간 (306개). 등산 코스 구성 시 제외하거나
   '산책 코스' 카테고리로 별도 활용.
3. 고도 없음. 원본 GPX의 ele가 전부 0. 고도 그래프/누적고도는
   추후 DEM(수치표고모델) 후처리 필요.
4. 2016년 조사 데이터. 시설물 위치·폐쇄 구간은 답사로 검증 필수.
   safety_points의 표지판 번호도 실물 대조 전까지 참고용으로만 표시할 것.
5. difficulty는 원본 표기(쉬움/중간/어려움) 그대로. 표준화 난이도 지수는
   구간 합산(length_km, up_min) 기반으로 앱에서 계산 권장.

## Supabase 임포트

1. schema.sql 실행
2. Table Editor > Import CSV 순서: mountains → nodes → segments → spots → safety_points
   (entrances.csv는 spots의 부분집합이라 임포트 불필요, 뷰 사용)
