# 산노트 (sannote)

수도권 2030 등산 초보를 위한 입구·코스 단위 등산 코스 정보 앱.

## 개발 환경
- Flutter는 FVM으로 고정 (`.fvmrc`). 모든 명령은 `fvm flutter ...`, `fvm dart ...`
- 키 설정: `cp .env.example .env` 후 값 채우기 (`.env`는 커밋 금지)
- 실행: `fvm flutter run`

문서: `CLAUDE.md`(프로젝트 규칙), `BACKLOG.md`(마일스톤), `SETUP.md`(초기 세팅), `seed/`(시드 데이터)
